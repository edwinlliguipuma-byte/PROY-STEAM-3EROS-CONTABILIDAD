Funciones Exponenciales

Una función exponencial tiene la forma f(x) = aˣ donde a > 0 y a ≠ 1.

🔍 Propiedades Fundamentales

  • Dominio: Todos los reales ℝ
  • Recorrido: (0, +∞) - siempre positivo
  • Asíntota horizontal: y = 0 (eje X)
  • Pasa por: el punto (0, 1)

📐 Función Desplazada

Cuando la función tiene la forma f(x) = aˣ + k:

Asíntota horizontal: y = k
Recorrido: (k, +∞)

📊 Ejemplo: f(x) = 2ˣ - 4

Análisis:
• Dominio: ℝ (todos los reales)
• Asíntota horizontal: y = -4
• Recorrido: (-4, +∞)
• Pasa por: (0, -3) porque 2⁰ - 4 = 1 - 4 = -3
📈 Gráfica de f(x) = 2ˣ - 4

🔢 Propiedades de los Logaritmos

El logaritmo es la operación inversa de la exponenciación: log_a(b) = c significa a = b.

📐 Propiedades Fundamentales

log(a · b) = log(a) + log(b)
log(a/b) = log(a) - log(b)
log(aⁿ) = n · log(a)

Casos Especiales

  • log_a(1) = 0 (porque a⁰ = 1)
  • log_a(a) = 1 (porque a¹ = a)
  • log_a(aⁿ) = n

📊 Ejemplo Resuelto

Calcular: E = log₂(8) + log₂(4)
Solución:
• log₂(8) = 3 (porque 2³ = 8)
• log₂(4) = 2 (porque 2² = 4)
• E = 3 + 2 = 5

📉 Funciones Logarítmicas

La función logarítmica g(x) = log_a(x) es la inversa de la función exponencial f(x) = aˣ.

🔍 Propiedades

  • Dominio: (0, +∞) - solo valores positivos
  • Recorrido: ℝ (todos los reales)
  • Asíntota vertical: x = 0 (eje Y)
  • Pasa por: el punto (1, 0)

🎯 Simetría

La gráfica de g(x) = log_a(x) es simétrica a f(x) = aˣ respecto a la recta y = x.

📊 Simetría entre exponencial y logarítmica

⚡ Ecuaciones Exponenciales

Para resolver ecuaciones exponenciales, se igualan las bases y luego los exponentes.

📐 Método de Resolución

Si a = aⁿ, entonces m = n

📊 Ejemplos Resueltos

Ejemplo 1: Resolver 3ˣ = 81
• 81 = 3⁴
• Entonces 3ˣ = 3⁴
• x = 4
Ejemplo 2: Resolver 2ˣ = 64
• 64 = 2⁶
• Entonces 2ˣ = 2⁶
• x = 6
Ejemplo 3: Resolver 4ˣ = 8
• 4 = 2² y 8 = 2³
• (2²)ˣ = 2³ → 2²ˣ = 2³
• 2x = 3 → x = 3/2

🧬 Sucesiones - Proyecto STEAM

Las sucesiones modelan el crecimiento de poblaciones celulares en el proyecto "Cáncer y Autómatas Celulares".

Sucesión Geométrica

aₙ = a₁ · r^(n-1)

Donde a₁ es el primer término y r es la razón.

🔬 Modelos de Proliferación

  • Si se duplica: r = 2, fórmula: aₙ = a₁ · 2^(n-1)
  • Si se triplica: r = 3, fórmula: aₙ = a₁ · 3^(n-1)

📝 Ejemplos Integradores

Ejemplo 1: Función Exponencial

Problema: Para f(x) = 2ˣ - 4, determine dominio, recorrido y asíntota.

Solución:
• Dominio: ℝ
• Asíntota: y = -4
• Recorrido: (-4, +∞)

Ejemplo 2: Logaritmos

Problema: Simplificar log₃(27) - log(3)

Solución:
• log₃(27) = 3 (3³ = 27)
• log₃(3) = 1
• Resultado: 3 - 1 = 2

Ejemplo 3: Ecuación Exponencial

Problema: Resolver 2ˣ = 64

Solución:
• 64 = 2
• x = 6

Ejemplo 4: Sucesión (STEAM)

Problema: Células que se triplican con a₁ = 2. Hallar a₄ y la fórmula.

Solución:
• r = 3, fórmula: aₙ = 2 · 3^(n-1)
• a₄ = 2 · 3³ = 2 · 27 = 54 células
